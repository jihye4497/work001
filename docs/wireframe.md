# 오늘의 장바구니 와이어프레임

2026-11-11 사용자 승인 개편. `docs/plan.md` 최신 승인 범위와 `docs/style_guide.md` 10절을 따른다. 기존 12개 화면의 순서를 유지한다.

## 관심 선택·시각 위계 보완 (2026-11-11)

- 순서: 검색 → 색상 배경의 추천 방식 → 보조 조건처럼 보이는 음식 종류 가로 스크롤 → 관심 활용일 때만 관심 재료 → 결과다. 방식 밑줄은 제거한다.
- 자동 추가 재료는 목록에만 넣고 활성 선택은 하지 않는다. 기존 활성 선택은 유지한다. 직접 재료 선택 화면에서 고른 재료의 기존 활성화 동작은 유지한다.
- 관심 제목 옆 한 버튼은 전부 선택이면 모두 해제, 일부/없음이면 모두 선택이다. 재료가 없으면 비활성이다. 목록 자체와 장보기 재료·수량은 바꾸지 않는다.

## 메뉴 자동 재료·표시 우선순위 (2026-11-11)

- 메뉴 검색 담기와 추천 담기는 선택 메뉴에 연결된 미보유 일반 재료를 관심 재료에 추가한다. 선택 메뉴 삭제 시 해당 메뉴에만 연결된 재료를 정리한다. 공유 재료와 직접 선택은 유지한다. 양념은 구매/보유 장보기에 반드시 포함한다.
- 메뉴명을 먼저 보도록 카드의 반복 이유 문단을 제거하고 ⋯의 자세한 이유를 유지한다. 기준 인분·담기·제외·횟수 기능은 그대로다.
- 홈은 제목·짧은 보조 문구·세 단계·시작 버튼과 선택 펼침 방식 설명으로 줄인다. 별도 가이드 강조 대신 바닥글 링크를 유지한다.

## 메뉴 검색 보완 (2026-11-11)

- 한 글자 이상 입력 → 검색창 아래 전체 메뉴 이름 목록(기준 인분·담기/담김) → 8개씩 더 보기. 빈 입력에는 숨긴다. 이름 검색은 관심·종류·추천 제외와 무관하다.
- 검색 행 클릭 → 중복 없이 1회로 담기 → 검색 비우기·추천 복귀·알림. 이미 담은 행은 비활성이다. 방향키로 검색 행 접근·Enter/Space 선택·Esc 닫기를 지원한다.
- 직접 담은 메뉴도 모든 재료·양념을 장보기에 합산하며 보유 여부로 구분한다. 추천 조건 때문에 재료를 빼지 않는다.

## 최신 승인 수정 (2026-11-11)

아래 초기 상자 그림·배치와 충돌하면 이 절을 우선한다.

- 홈: 승인된 세 단계 문구 → 최초 인원 설정(설정 후 생략) → 재료 선택하러 가기 → 추가 구매 최소/관심 재료 활용 설명. 홈 보유 입력과 추천 화면 안내 펼침은 제거한다.
- 재료 선택: 집에 있는 재료 N/새로 살 관심 재료 N 두 탭 → 검색 → 선택 요약 → 네 카테고리 → 등록 재료 20개 → 추천 메뉴. 안내 문단 없음. 보유 수정 링크는 ingredients.html?tab=pantry로 연결한다. 옛 홈 #pantry는 이 주소로 보낸다.
- 추천 메뉴: 검색 → 두 방식 → 관심 활용 모드에서만 관심 재료 선택 → 항상 보이는 음식 종류 가로 스크롤 → 결과 → 하단 선택 확인·장보기. 구매 최소는 관심 활성 상태와 무관하게 구매 예정+보유 전체를 고려하며 보유 재료만으로도 추천한다. 빈 재료·빈 후보·검색·오류 안내는 유지한다.
- 장보기·설정·기존 저장·단위 계산·제외 관리 기능은 유지한다.

## 최신 승인 배치 (2026-11-11)

이 절과 docs/style_guide.md 12절이 아래 초기 상자 그림보다 우선한다. 기존 12개 화면·경로·기능은 유지한다.

1. 홈: 짧은 소개·단계 아이콘 → 최초 인원 선택(이미 설정하면 생략) → 보유 재료 검색 → 선택 재료 요약 펼침 → 카테고리 한 줄과 해당 재료 → 새로 살 재료 고르기.
2. 기본 설정: 인원·두 방식·보유 재료 수정·제외 관리 유지.
3. 재료 선택: 새로 살 재료 검색 → 선택 요약 펼침 → 카테고리 한 줄·해당 재료 → 추천 메뉴. 검색은 전체 재료 대상이다.
4. 추천 메뉴: 전체 메뉴 검색 → 두 추천 방식 → 방식 설명 펼침 → 관심 재료 버튼 → 음식 종류 펼침(현재 선택 표시) → 2열 결과·더 보기 → 하단 선택 메뉴 확인·장보기 이동. 검색은 여전히 전체 메뉴 대상이며 검색 지우기로 추천 복귀한다.
5. 장보기 목록: 선택 메뉴 최초 3행·−/횟수/+·⋯ → 나머지 더 보기 → 구매 수·체크 수·목록 복사 → 구매할 재료 → 집에 있는 재료 N종 펼침 → 안내·이동·기존 새 장보기 버튼. 회색 메뉴별 내역은 재료 버튼으로 펼친다. 체크는 펼침 상태를 바꾸지 않는다.

- 선택 메뉴의 관리 ⋯는 삭제와 부위 대체 근거를 연다. 횟수 변경은 닫힌 상태에서도 가능하며 합산을 즉시 갱신한다.
- 양념은 별도 구획을 없애고 보유 여부로 구매/보유 구획에 넣는다. 자동 보유 가정은 하지 않는다. 목록 복사는 접힌 항목도 전부 포함한다.
- 처음/로딩/저장 오류/없는 결과 안내와 기존 제외 관리·초기화 확인·원본 단위 보존은 유지한다.
- 새 장보기 버튼의 재배치는 이번 작업에서 제외한다.

## 최신 디자인 적용 (2026-11-11)

- 아래 기능 배치·화면 순서는 유지하고 docs/style_guide.md 11절의 흰 배경 디자인을 적용한다.
- 상단 탭은 초록 채움 버튼 대신 글자·3px 밑줄로 활성 상태를 표시한다. 중복 큰 제목은 계속 시각적으로 숨긴다.
- 홈 인원·보유 재료, 재료 선택, 선택 메뉴, 장보기 구획은 외곽 상자 대신 여백과 구획 선으로 나눈다. 재료 선택 수와 선택 칩은 한 줄에 두되 좁으면 줄바꿈한다.
- 추천 카드는 2열 회색 면, 선택된 재료·메뉴는 연초록 면, 다음 단계 버튼은 진한 초록 면이다. 기존 선택·상태·이동·초기화 동작은 유지한다.

## 0. 전체 흐름

```text
홈(인원·집에 있는 재료) → 재료 선택(새로 살 재료) ⇄ 추천 메뉴 ⇄ 장보기 목록
홈 로고 ← 모든 화면                  └ 전체 메뉴 검색으로 직접 담기
모든 화면 → 기본 설정 → 저장 후 호출 화면으로 복귀
추천 메뉴 / 장보기 목록 → 선택 메뉴 클릭 → 횟수 변경·삭제
장보기 목록 → 복사·구매 체크 → 종료·재방문 시 복원
장보기 목록 → 새 장보기 시작 → 확인 후 현재 작업만 초기화 → 재료 선택
```

- 사용자 승인(2026-11-11): 재료 선택·추천 메뉴·장보기 목록의 중복 큰 제목은 시각적으로 숨긴다. 상단 탭은 개별 테두리 버튼으로 표시하고 현재 화면은 초록 배경·흰 글자로 구분한다.
- 공통 상단: 기존 SVG 로고·오늘의 장바구니 홈 링크, `N명 · 설정`; 다음 행 재료 선택/추천 메뉴/장보기 목록 3등분. 48px+48px 고정, 활성 밑줄+aria-current다. 결제·종료 전용 화면은 없다.
- 공통 바닥글: 장보기 가이드·서비스 소개·문의·개인정보처리방침·이용 안내. 저장 오류는 상단 알림에 표시한다.
- 인원·재료·방식·음식 종류 변경으로 기존 메뉴·횟수를 지우지 않는다. 최초 최대 8개, 8개씩 더 보기다. 조건에 맞는 메뉴가 없으면 빈 상태를 표시한다.
- 선택 메뉴: 2열(768px 이상 3열), `김치찌개 ×1회` 다음 줄 `4인분 기준`. 처음 3개·전체 펼치기. 클릭 시 −/횟수/+/삭제가 같은 항목 아래 열린다. 인원은 반복하지 않는다.
- 사용자 확인 1인분은 `1인분 기준`, 원문 명시 2·4인분은 원문 기준을 표시한다. 현재 데이터에 추정 문구를 붙이지 않는다.
- 광고 승인 전 모든 화면 0개·빈 자리 없음. 승인 후 홈·추천 메뉴·장보기 목록·오징어 활용 가이드 하단 최대 1개씩. 본문 32px·버튼 48px 이격, 빈 결과·오류에는 숨긴다.

### 1. 홈 — `/` · `index.html`

- 목적: 소개를 읽고 식사 인원과 집에 있는 재료를 선택한다.

```text
┌────────────────────────┐
│ 로고·이름       N명·설정│
│ 재료 선택 | 메뉴 | 목록 │
├────────────────────────┤
│ 오늘 뭐 담지?          │
│ 고른 재료가 계획이 돼요 │
│ 01 재료 → 02 메뉴 → 03 목록│
│ 보통 몇 명이 드시나요? │
│ [1명] [2명] [3명] [4명] │
│ 집에 있는 재료         │
│ [재료명 검색_________] │
│ 선택한 재료 N개 [양파×]│
│ 채소·버섯 [양파][감자] │
│ 육류·해산물 […]        │
│ 두부·계란·기타 […]     │
│ 양념·조미료 […]        │
│ [새로 살 재료 고르기 →]│
│ 장보기 가이드          │
│ [광고: 승인 후 1개]    │
│ 공통 바닥글            │
└────────────────────────┘
```

| 요소 | 내용(실제 문구 예시) | 누르면 일어나는 일 |
|---|---|---|
| 식사 인원 | `보통 몇 명이 드시나요?` / 1~4명 | 즉시 기본 인원 저장, 선택 메뉴 필요량에 적용 |
| 보유 재료 검색·버튼 | `양파`, `감자`, `소금` | 등록 재료를 보유 목록에 추가·해제, 수량 입력 없음 |
| 다음 행동 | `새로 살 재료 고르기 →` | 재료 선택 이동, 기존 작업 유지 |

- 상태: 처음은 1명·보유 재료 없음; 불러오는 중은 재료 상태 문구; 정상은 저장된 인원·보유 재료; 오류는 재시도 또는 저장 실패 알림이다. 재료는 자동으로 보유 처리하지 않는다.
- PC에서 달라지는 점: 최대 1120px, 소개 읽기 폭 720px; 선택 영역은 한 열이다.
- 연결된 plan.md 작업 번호: 2-3, 3-1, 3-2, 6-1, 6-2 및 최신 승인 범위.

### 2. 기본 설정 — `/settings.html`

- 목적: 기본 인원·방식을 수정하고 제외한 메뉴를 관리한다.

```text
┌────────────────────────┐
│ 공통 상단              │
│ 기본 설정              │
│ 인원 [1명][2명][3명][4명]│
│ [추가 구매 최소]       │
│ [관심 재료 활용]       │
│ 방식 설명·예시         │
│ [저장하고 돌아가기]    │
│ [집에 있는 재료 수정]  │
│ [제외한 메뉴 관리 · N개]│
│ 공통 바닥글            │
└────────────────────────┘
```

| 요소 | 내용(실제 문구 예시) | 누르면 일어나는 일 |
|---|---|---|
| 인원·방식 | `기본 식사 인원`, `기본 추천 방식` | 폼에서 선택, 저장 시 적용 |
| 보유 재료 수정 | `집에 있는 재료 수정` | 홈의 보유 재료 영역으로 이동 |
| 제외 관리 | `제외한 메뉴 관리 · N개` | 검색·최초 10개/10개씩 더 보기·개별 복원·전체 복원 확인·실행 취소 관리창 |

- 상태: 처음은 기본값; 불러오는 중은 제외 관리 데이터 요청 중; 정상은 저장된 값; 오류는 저장·불러오기 실패 알림이다. 관리창을 닫아도 저장 전 폼 값은 유지한다. Esc·닫기 후 호출 버튼으로 포커스를 돌린다.
- PC에서 달라지는 점: 설정 폼 최대 640px; 제외 관리창 최대 720px·높이 85dvh, 휴대폰은 전체 화면이다.
- 연결된 plan.md 작업 번호: 2-2, 2-3, 6-2 및 최신 승인 범위.

### 3. 재료 선택 — `/ingredients.html`

- 목적: 새로 살 재료를 여러 개 선택한다.

```text
┌────────────────────────┐
│ 공통 상단              │
│ 재료 선택              │
│ 새로 살 재료           │
│ [집에 있는 재료 수정]  │
│ [재료명 검색_________] │
│ 선택한 재료 N개        │
│ [오징어 ×] [새우 ×]    │
│ 채소·버섯 / 육류·해산물│
│ 두부·계란·기타 / 양념  │
│ 카테고리별 재료 버튼   │
│ [추천 메뉴 →]          │
│ 재료 없이 메뉴 검색 가능│
│ 공통 바닥글            │
└────────────────────────┘
```

| 요소 | 내용(실제 문구 예시) | 누르면 일어나는 일 |
|---|---|---|
| 재료 검색 | `예: 오징어, 양파` | 표준명·동의어 검색, 최대 30개 자동완성, 방향키·Enter·Esc 지원 |

| 삭제 안내 | `새 장보기 시작은 현재 장보기 작업만 지워요. 기본 설정까지 지우려면 브라우저의 사이트 데이터를 삭제해 주세요.` | 안내만; 이 화면에 초기화 버튼 추가 안 함 |
| 분석·광고 현황 | 실제 도입 도구·처리 목적·범위·외부 제공 등 확인된 내용 | 확인된 외부 정책 링크가 있을 때만 연결 |
| 문의 | `문의` | 문의 이동 |

- 상태: 처음/정상은 실제 운영과 일치하는 본문. 불러오는 중은 해당 없음. 오류는 문서 요청 오류 시 오류 페이지. 분석 도구 미정·광고 미승인 상태를 도입 완료처럼 쓰지 않으며 필수 고지는 7-4·7-8에서 확정한다. 이 명세는 법률 문안이 아니다.
- 광고 개수: 0개.
- PC에서 달라지는 점: 720px 한 열, 본문 16px·26px 유지.
- 연결된 plan.md 작업 번호: 6-1, 6-3, 7-4, 7-8.

### 11. 이용 안내 — `/terms.html`

- 목적: 수량 계산과 추천·구매 판단의 범위를 이해한다.
- 배치:

```text
┌────────────────────────┐
│ 공통 상단               │
├────────────────────────┤
│ 이용 안내               │
│ 서비스 이용 방법        │
│ 기본 식사 인원·조리 횟수│
│ 원문 단위·수량 미기재  │
│ 구매 포장 단위는 직접 확인│
│ 브라우저 저장의 범위    │
│ [문의]                  │
│ 공통 바닥글             │
└────────────────────────┘
```

| 요소 | 내용(실제 문구 예시) | 누르면 일어나는 일 |
|---|---|---|
| 계산 안내 | `기본 식사 인원과 조리 횟수에 따라 필요한 양을 계산해요.` | 없음 |
| 단위 안내 | `서로 다른 단위는 합치지 않아요. 확인할 수 없는 양은 수량 미기재로 표시해요.` | 없음; 계량 단위 환산 기능 추가 안 함 |
| 판단 안내 | `최종 구매 여부와 포장 단위는 직접 확인해 주세요.` | 없음 |
| 저장 안내 | `다른 기기나 브라우저로 자동 동기화되지 않아요.` | 없음 |
| 문의 | `문의` | 문의 이동 |

- 상태: 처음/정상은 검수된 정적 이용 안내. 불러오는 중은 해당 없음. 오류는 요청 오류 시 오류 페이지. 운영·책임 문구는 실제 조건에 맞춰 확정하며 무제한 면책 등 임의 조항을 만들지 않는다.
- 광고 개수: 0개.
- PC에서 달라지는 점: 720px 한 열, 섹션 간 32px.
- 연결된 plan.md 작업 번호: 7-4.

### 12. 오류 페이지 — `/404.html`

- 목적: 잘못된 주소에서 홈이나 진행 중인 장보기로 돌아간다.
- 배치:

```text
┌────────────────────────┐
│ 공통 상단               │
├────────────────────────┤
│ 오류 페이지             │
│ 페이지를 찾을 수 없어요.│
│ 주소를 확인하거나 아래 │
│ 화면으로 이동해 주세요.│
│ [홈]                    │
│ [재료 선택]             │
│ 공통 바닥글             │
└────────────────────────┘
```

| 요소 | 내용(실제 문구 예시) | 누르면 일어나는 일 |
|---|---|---|
| 제목·설명 | `오류 페이지`, `페이지를 찾을 수 없어요.` | 없음; 요청 URL을 HTML로 삽입하지 않음 |
| 홈 버튼 | `홈` | `/` 이동, 저장 상태 유지 |
| 복귀 버튼 | `재료 선택` | `/ingredients.html` 이동, 기존 메뉴·재료·횟수 유지 |

- 상태: 처음(데이터 없음)에도 두 이동 버튼 표시. 불러오는 중은 해당 없음. 정상은 404 안내가 정상적으로 렌더링된 상태. 오류는 JS·저장소 오류여도 순수 HTML 링크가 동작하며 작업을 초기화하지 않는다.
- 광고 개수: 0개.
- PC에서 달라지는 점: 안내 영역 최대 640px 가운데 정렬, 버튼은 가로·gap 16px. 헤더·푸터는 공통 정렬 유지.
- 연결된 plan.md 작업 번호: 1-3, 7-6.

- 사용자 승인 변경(2026-11-11): 재료 선택 두 탭의 선택 재료 요약은 접지 않고 개수와 전체 선택 태그를 바로 표시한다. 색상·탭 디자인 변경은 보류한다.

- 최신 승인(2026-11-11): 재료 선택 두 탭 안의 배치는 선택 재료 → 카테고리 4개 → 전체 재료 검색 → 재료 목록 순이다. 검색 범위는 현재 카테고리에 제한하지 않는다.

- 최신 승인(2026-11-11): 검색은 추천 제목 바로 아래, 관심 재료는 가로 스크롤이다. 검색/추천 담기 모두 전후 구매 재료 ID를 비교한 추가 알림을 표시한다. 보유·기존 구매 제외, 없는 양념 포함, 수량만 변경/구매 없음 구분, 전체 보기와 닫기를 제공한다. 알림은 자동 소멸하지 않으며 다음 담기는 새 알림으로 교체한다.


## 전체 디자인 재설계 적용 (2026-11-11 최신 승인)

- 기존 화면·기능 순서는 유지하고 시각 표현은 docs/style_guide.md 16절을 우선한다.
- 공통: 흰 헤더 → 아이콘·텍스트 이동 탭 → 중립 바탕의 해당 작업. 재료 구분과 추천 방식은 동일한 세그먼트 형태로 표현한다.
- 홈: 큰 짧은 제목 → 세 단계 안내 → 최초 인원 선택 → 주요 시작 버튼. 휴대폰 단계 안내는 세 행이다.
- 재료 선택: 구분 탭 → 선택 칩 → 네 카테고리 → 검색 → 미선택 재료 → 추천 메뉴 이동이다. 보유·관심 색은 선택 칩에서만 구분한다.
- 추천: 방식 → 음식 종류 → 관심 활용일 때 관심 칩 → 추천 제목·검색 → 두 열 카드 → 하단 선택 메뉴·장보기 이동이다.
- 장보기: 선택 메뉴 흰 패널 → 구매 목록 흰 패널(제목, 전체 선택/복사/구매 제외, 재료 행) → 중립 보유 펼침 → 중립 제외 펼침 → 기존 안내·이동·초기화이다.


- 최신 승인(2026-11-11): 추천 카드 상단 공식 사진(1.6:1) → 메뉴명 → 기준 인분 → 담기/더 보기. 원본 ID·이름 매칭 사진만 표시하며 없음/오류 시 사진 영역 생략. 2열 유지, 검색·장보기는 기존 텍스트 유지.

- 최신 승인(2026-11-11): 검색/추천 담기 → 확인 모달(메뉴명, 새로운 재료, 관심 재료, 아니요/네 담기) → 확인에서만 반영. 보유 재료는 숨기고 구매 없음이면 집에 있는 재료로 만들 수 있어요 표시. 취소/Esc 변경 없음. 기존 사후 재료 추가 알림은 제거한다.
