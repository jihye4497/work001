# 오늘의 장바구니

HTML5·CSS3·JavaScript ES Modules로 만든 모바일 우선 장보기 웹사이트입니다. 빌드·패키지 설치·API 키가 필요하지 않습니다.

## 로컬 실행

프로젝트 루트에서 Python 3가 설치된 환경 기준으로 실행합니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. 파일을 더블클릭하는 `file://` 방식은 ES Modules와 JSON 로딩을 지원하지 않습니다. 서버를 종료하려면 실행한 터미널에서 Ctrl+C를 누릅니다.

## 자동 확인

Node.js 22.18 이상(현재 개발 환경: 26.13.0)의 기본 테스트 실행기를 사용하며 라이브러리는 설치하지 않습니다.

```powershell
node --test tests/*.test.mjs
git diff --check
```

테스트는 데이터 검증, 표준 재료 검색, 인원·횟수 계산, 같은 단위 합산, 다른 단위 분리, 수량 미기재, 양념 분류, 추천 두 방식과 동점, 8개씩 표시, 저장 복원·오류·초기화를 확인합니다. 화면 전체의 브라우저 검증을 대신하지 않습니다.

## 직접 확인

1. 홈에서 인원·집에 있는 재료를 고르고 새로 살 재료 선택으로 이동합니다.
2. 재료 선택에서 양파·감자를 고르고 추천 메뉴으로 이동합니다.
3. 메뉴 두 개를 담고 선택 메뉴를 눌러 조리 횟수를 바꿉니다.
4. 재료 선택으로 돌아가 오징어를 추가합니다. 기존 메뉴·횟수가 남는지 확인합니다.
5. 추천 메뉴에서 두 방식 탭을 바꿔 본 뒤 장보기 목록으로 갑니다.
6. 사용 메뉴·총량을 확인하고 구매 체크·목록 복사를 사용합니다.
7. 새로고침·화면 왕복 후 내용이 남는지 확인합니다.
8. 새 장보기 시작에서 취소하면 유지되고 확인하면 현재 작업만 지워지는지 확인합니다.
9. 360px·768px·1280px에서 가로 스크롤, 키보드 조작, 버튼 가림을 확인합니다.

## 음식 종류·추천 제외·모바일 화면

- 추천 방식 아래에서 음식 종류를 여러 개 고릅니다. `전체`는 개별 선택을 해제합니다. 한식 주메뉴·반찬·국·찌개와 양식·일식·중식·그 밖·퓨전을 지원합니다. 여러 종류의 합집합을 두 방식으로 정렬하며 같은 메뉴는 한 번만 표시합니다.
- `data/recipe-categories.json`은 메뉴 ID별 탐색용 편집 분류입니다. 한식 밥·면·죽은 주메뉴에 포함합니다. 퓨전 여부는 서비스 편집 판단이므로 향후 수정할 수 있습니다. 새 레시피를 추가하거나 이름을 바꾸면 이 파일도 검토해야 합니다. 원문 수량·인분은 변경하지 않습니다.
- 카드의 `⋯ → 앞으로 추천받지 않기`로 제외하고 실행 취소할 수 있습니다. 기본 설정의 `제외한 메뉴 관리`에서 전체 제외 목록을 검색하고 10개씩 확인·복원합니다. 전체 복원은 확인을 거칩니다. 창을 닫아도 저장 전 기본 설정 입력은 유지합니다.
- 제외 설정은 같은 브라우저의 `jmd_recipe_preferences_v1`에 저장합니다. 새 장보기·기본 설정 변경 후에도 유지하고, 기존 선택 메뉴·조리 횟수·장보기 계산에는 영향을 주지 않습니다. 음식 종류 선택은 `jmd_draft_v1.selectedFoodCategories`에 저장합니다. 예전 저장값은 메뉴·횟수를 보존하며 전체 종류로 복원합니다.
- 상단의 `인원 · 설정`과 내비게이션은 고정합니다. 선택 메뉴는 처음 3개와 전체 펼치기를 제공하고 메뉴명·기준 인분·횟수를 한 버튼으로 표시합니다. 추천 방식은 2개 버튼, 음식 종류는 한 줄 가로 스크롤이며 카드 하단에 담기·더 보기를 배치합니다. 본문 16px·터치 영역 48px을 유지합니다. 레시피 상세·조리 순서 창은 이번 작업 범위가 아닙니다.
- 회귀 확인: 재료에서 양파 선택 → 추천 방식 전환 → 한식 주메뉴+한식 반찬 선택 → 메뉴 담기·횟수 변경 → 다른 메뉴 제외·실행 취소 → 기본 설정에서 제외 관리·검색·복원 → 새 장보기 후 제외 설정 유지 확인. 실제 360px·768px·PC 시각 검증은 브라우저 연결 복구 후 확인해야 합니다.
- 전체 자동 테스트: `node --test tests/*.test.mjs`. `tests/app-flow.test.mjs`는 DOM 테스트 대역으로 이벤트 연결을 검증하며 실제 브라우저 렌더링 검증을 대신하지 않습니다.

## 초기 데이터와 검수 범위

현재 메뉴는 **1,033개**입니다. 2026-11-11에 미등록 메뉴 580개를 추가했습니다. 기존 테팔 8개 + 식품안전나라 원문 명시 인분 60개 + 사용자 확인 인분 965개로 구성됩니다. 기존 메뉴 ID·재료량·원문 단위와 브라우저 저장 키는 유지합니다.

- 표준 ID 기준 양파 428개, 팽이버섯 35개, 감자 87개, 오징어 27개, 계란 152개 메뉴가 있습니다. 다른 부위나 다진 형태를 이 수에 임의로 합치지 않습니다. 모든 재료에서 8개를 보장하지 않으며 이미 담거나 제외한 메뉴는 추천에서 빠집니다.
- 인분 미표기 메뉴는 사용자 직접 확인·승인(2026-11-11)에 따라 `user-confirmed`·1인분 기준을 사용합니다. 원문 명시 2·4인분 등을 우선합니다. 공식 원문 전체를 검증했다는 의미가 아니며, 확인 주체·날짜·이전 추정 근거를 내부 검수 기록에 보관합니다. 화면·장보기·복사에는 추정 문구를 붙이지 않습니다.
- 소제목과 식재료를 분리하고, 동일 의미의 표기·원문 오타는 검토한 별칭으로 연결했습니다. 서로 다른 고기 부위를 같은 재료로 바꾸지는 않습니다. 부위 대체 추천은 별도 작업입니다.
- 단위가 없거나 하나의 숫자로 정할 수 없는 수량은 원문 메모와 `수량 미기재`를 유지합니다. 단위 미기재 89항목을 g으로 추정하지 않습니다. 원문에 병기된 수량만 사용하며 g·mL·T·t·Ts·ts를 서로 변환하지 않습니다. 치즈리조또 우유 180mg도 유지합니다.
- 신규 메뉴의 음식 종류는 메뉴명·원본 요리종류에 따른 초기 편집 분류입니다. 기존 453개의 분류를 유지하며 추가 분류는 앞으로 조정할 수 있습니다.

출처는 [테팔 공식 레시피북](https://dam.groupeseb.com/m/72b0457b12251391/original/TEFAL_CY7551KR_Recipe-Book.pdf)과 식품의약품안전처 COOKRCP01입니다. [API 공식 안내](https://www.foodsafetykorea.go.kr/api/newDatasetDetail.do?svc_no=COOKRCP01), [이용 조건 메타정보](https://www.data.go.kr/catalog/15060073/openapi.json)를 참고합니다. 사진·조리 설명을 복제하거나 영양 효과를 주장하지 않습니다.

## 식품안전나라 수집·검사

2026-11-10 수집한 API 1,156개와 보완 원문 2개를 검사합니다. 현재 식품안전나라 메뉴 1,025개를 사용하며 원문 133개가 남았습니다. 남은 항목은 제빵·제과 51개, 이름 중복 후보 13개, 원문·표기 추가 확인 69개입니다. 마지막 69개에는 재료 목록 공란 3개와 메뉴명 불일치 1개가 포함됩니다. 인분 때문에 보류한 목록과 혼동하지 않습니다.

제빵 제외는 이름에 `빵`이 있는지만 보지 않습니다. 빵가루 생선·빵 대신 어묵 사라다는 포함하고, 콩가루 소보로·브레드 스틱·버터롤·바케트·밀푀유 과자 등 실제 제빵·제과는 제외합니다. 예전 이름 검색 기준 46개보다 5개를 추가로 구분했습니다. 같은 이름이더라도 다른 구성인 메뉴는 비교 후 처리하며 자동으로 제목·수량을 만들지 않습니다.

- `data/source/mfds-response.json`: 수집한 전체 원문 1,156개. 인증키는 저장하지 않습니다.
- `data/source/mfds-supplement.json`: 공식 SAMPLE 페이지의 보완 원문 2개.
- `data/source/mfds-page2.json`: 동일 샘플 반복 반환을 확인했던 테스트 원문.
- `data/source/mfds-expansion-policy.json`: 사용자 승인 날짜·인분 기준·원본 해시.
- `data/source/mfds-ingredient-review.json`: 검토한 재료 카테고리·별칭·소제목·추가 제빵 제외 ID.
- `data/source/mfds-reviews.json`: 원문 구절·해시·원문 수량·단위·인분의 검수 기록. 이전 인분 근거도 보존합니다.
- `data/source/mfds-expansion-report-2026-11-11.json`: 추가 580개와 남은 133개의 구체적 사유. 재실행해도 과거 추가 이력을 유지합니다.
- `data/source/mfds-expansion-report.json`: 2026-11-10의 이전 검토 기록으로, 현재 상태는 최신 보고서를 사용합니다.
- `data/source/mfds-import-report.json`: 전체 검사·보류·재료별 메뉴 수 보고서.
- `data/recipe-categories.json`: 사이트에 제공하는 전체 메뉴의 음식 종류.

검수만 실행하며 원본 해시가 달라지면 중단합니다.

```powershell
node scripts/expand-mfds.mjs --all-reviewed
```

검수 결과를 저장하려면 다음 명령을 실행합니다. 모든 출력을 검증한 뒤 기록하며 기존 메뉴 ID가 사라지는 결과는 저장하지 않습니다. 다시 실행해도 메뉴를 중복 추가하지 않습니다.

```powershell
node scripts/expand-mfds.mjs --all-reviewed --write
node scripts/import-mfds.mjs
```

기존 `review-mfds.mjs`·`review-estimated-servings.mjs`는 초기 검토 기록 재현용입니다. 현재 확대 데이터에 예전 추정 정책을 다시 적용하지 않습니다. API 인증키는 채팅·소스·명령 인자에 넣지 않습니다. 기존 원문으로 재검사할 때에는 키가 필요하지 않습니다.

운영자의 최종 검수(계획 2-4·7-3)는 미완료입니다. 아직 남은 원문·분류·표기는 후속 검토하고 레시피 수량을 임의로 생성하지 않습니다.

## 공개 전 남은 작업

- 실제 운영자 정보·문의 연락처·정책 시행일과 최종 문안을 확정합니다. 현재 안내 페이지에는 미정 상태를 명시했습니다.
- Cloudflare Pages 프로젝트와 GitHub 저장소를 사용자가 직접 연결합니다. 정적 사이트로 설정하고 프레임워크는 없음, 빌드 명령은 비움, 출력 디렉터리는 프로젝트 루트로 설정합니다. 실제 설정 UI와 자동 배포 상태를 확인합니다.
- 도메인을 확정한 뒤 `sitemap.xml`에 실제 URL을 추가하고 공개 준비가 끝나면 HTML의 `noindex, nofollow`와 `robots.txt`의 전체 크롤링 차단을 해제합니다. 현재 사이트맵은 빈 상태이며 검색 등록 준비 완료가 아닙니다.
- Cloudflare Pages가 잘못된 주소에 `404.html`을 반환하는지 배포 환경에서 확인합니다.
- Google Fonts 외 분석·광고 스크립트는 없습니다. 개인정보 안내에 실제 호스팅 로그 처리와 도입 도구를 반영합니다.
- AdSense 승인 전에는 광고를 넣지 않습니다. `ads.txt`는 빈 파일이며 가짜 게시자 ID를 넣지 않았습니다.

### 2026-11-11 보유 재료와 메뉴 탐색 개편

- 홈에서 인원·보유 재료를 선택하고 재료 선택에서는 새로 살 재료를 고릅니다. 보유량은 입력·차감하지 않습니다.
- 추천은 추가 구매 최소/관심 재료 활용 두 방식입니다. 관심 활용은 활성 재료 모두 포함, 주재료 활용 순입니다. 주재료 판정은 메뉴명·재료명 연결 규칙이며 전 메뉴 수작업 분류가 아닙니다.
- 추천 안의 검색창은 재료·종류·추천 제외와 관계없이 전체 메뉴를 찾습니다. 검색을 지우면 원래 추천으로 돌아옵니다.
- 모바일 카드 2열, 선택 메뉴 기준 인분 보조 표시, 장보기는 구매할 재료/집에 있는 재료/양념·조미료입니다.
- 돼지 목심/목살을 연결하고 김치찌개에서만 앞다리·목살·삼겹살 대체를 허용합니다. 실제 선택 부위로 합산하며 소고기·다짐육은 자동 대체하지 않습니다.
- 추가 검증: `node --test tests/pantry-flow.test.mjs tests/app-flow.test.mjs`. 실제 모바일 시각 확인은 브라우저 연결 도구 제한으로 미완료입니다.


### 최신 화면 구성 (2026-11-11)

- 홈 인원 선택은 처음에만 표시하고 이후 설정에서 수정합니다. 재료는 카테고리 하나씩 고르며 전체 검색과 선택 요약 펼침을 함께 제공합니다.
- 추천은 검색창부터 시작하고 방식 설명·음식 종류를 펼쳐 봅니다. 하단 선택 메뉴 확인에서 횟수·삭제를 편집합니다.
- 선택 메뉴는 최초 3행과 더 보기이며 −/+를 항상 표시합니다. 장보기 사용 내역은 재료명·총량을 눌러 펼치고 체크박스는 독립입니다.
- 양념도 보유 여부에 따라 구매/보유 두 구획으로 나뉩니다. 보유 구획은 기본 접힘이며 복사에는 접힌 항목도 포함합니다.
